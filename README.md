# River Freeze-Up and Breakup Prediction: Research Materials

## Overview

This repository provides selected research materials for the study *Prediction of River Freeze-Up and Breakup Dates Based on SAG-AL-ESN-HRCLRC Multi-Station Air-Temperature Forecasting and Reach-Specific Criteria*.

The study investigates a two-stage framework for river-ice event prediction. Multi-station air-temperature forecasting is performed in the first stage, followed by freeze-up and breakup date determination using reach-specific criteria.

## Study Areas

The experiments cover three river reaches: Harbin, Heihe, and Raohe. The repository will include descriptions of the study scenarios, meteorological observations, and selected evaluation results.

## Materials Currently Available

- Model and methodology overview
- Description of the study scenarios and meteorological data
- Selected temperature-forecasting results
- Selected freeze-up and breakup date comparison results

The contents of this repository will be updated as the research materials are prepared for release.
